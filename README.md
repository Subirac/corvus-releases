# Corvus — test builds

**Corvus** is a desktop app for writing in plain text and seeing it typeset beside you — then
exporting it to PDF, HTML or LaTeX.

**[⬇ Download the latest version](https://github.com/Subirac/corvus-releases/releases/latest)**
— the release page says which file your computer needs and how to install it (about a minute,
no technical steps).

From version 0.3.0 on, Corvus checks for new versions itself and offers to update — you only
download it once.

Found a bug, got confused, or wished it did something? Please tell us: reply to the message that
brought you here, or open an [issue](https://github.com/Subirac/corvus-releases/issues).
